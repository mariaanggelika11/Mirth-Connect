# Git history cleanup runbook

No rewrite, force push, or repository settings changes were performed. Historical findings do not prove a credential is still active; rotation must precede cleanup. Review sanitized findings generated by `node scripts/secret-scan.mjs --history`. The targeted scanner is not an exhaustive scanner; run Gitleaks with redaction on a secured clone and restrict reports to type/file/commit.

Coordinate a maintenance window with repository owners. Make an access-controlled mirror backup, inventory branches/tags/releases/forks, and prepare a separate mirror clone. The owner can use git-filter-repo to remove tracked environment/secret files after reviewing the exact paths. Review the sanitized result, rescan all rewritten refs, and test a fresh clone. Publish rewritten refs only with explicit owner approval; require collaborators to re-clone. Do not run these operations in this dirty workspace. Remove any exposed build/log artifacts and verify credential rotation at the issuers.

CI scans current files with Gitleaks and records targeted historical findings separately. Historical scanning is intentionally reported as unresolved rather than silently allowlisting historical exposure.
